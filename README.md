#  E-Commerce Customer Orders Data Cleaning Project

## 📌 Project Overview

This project demonstrates a complete data cleaning workflow on an e-commerce customer orders dataset.

The dataset contained multiple data quality issues including missing values, duplicate records, inconsistent formatting, invalid entries, and outliers. These issues were identified, documented, and corrected to prepare the dataset for accurate analysis.

This project was completed as a collaborative group assignment.

---

## 🎯 Objectives

- Identify data quality issues
- Explain why each issue affects analysis
- Clean and standardize the dataset
- Produce an analysis-ready dataset
- Document the cleaning process

---

## 🛠 Tools Used

- Microsoft Excel
  

---

## Data Cleaning Tasks

The following issues were addressed:

- Missing values
- Duplicate records
- Inconsistent capitalization
- Extra spaces
- Invalid email formats
- Incorrect date formats
- Negative quantities
- Price inconsistencies
- Data type corrections
- Outlier review
